프록시

프로필마다 다른 프록시를 Octo API로 자동 주입

Type: http   Mode: round_robin
gw.example.com:5959:user:pass
gw.example.com:5959:user2:pass2
검증 · 목록 반영 파일 불러오기
  • round_robin — 계정마다 프록시를 순서대로 바꿈 (권장)
  • from_selected — 목록에서 고른 줄부터
  • fixed — 한 개만 고정
  • 형식: host:port:user:pass

프로필

이메일 | 비밀번호 | 프로필명 | 2FA시크릿 | 2FA URL | 메모
─────────────────────────────────────
a@gmail.com · •••• · g-a-1 · 7DWQ… · 2fa-auth.com · pipe
b@gmail.com · •••• · g-b-2 · ABCD… · 2fa-auth.com · pipe
Google 로그인 + 2FA 자동
모드 auto · 시크릿 있으면 팝업 없이 6자리 자동 입력

홈에서 붙여넣기하면 여기 표가 자동으로 채워집니다.

  • 계정 1개 = Octo 프로필 1개 = 작업 1회
  • 각 행의 2FA시크릿만 그 계정 로그인에 사용 (서로 섞이지 않음)
  • 모드 auto = 아이디·비번·2FA 전부 자동 / skip = 로그인 안 함

6. 탭⑤ 베타 테스트

기능을 한 단계씩 검증할 때 사용합니다. 전체 원클릭 전에 연결·로그인만 확인하고 싶을 때 유용합니다.

  • T1~T5: 연결·프로필 등 기반
  • T6: Google 로그인
  • T7: 검색
  • T8: CTA

각 단계 후 평가(좋음/보통/문제)를 남길 수 있습니다.

10. 테스트 체크리스트 (이 순서대로)

테스트 전: Octo Browser 실행 + 로그인 필수. Base 이상 API 요금제·API 토큰 준비.
1
연결만 테스트
홈 ① 토큰 입력 → [연결 테스트] → Offline 이 아니고 Cloud OK / Local OK 인지 확인
2
계정 1개만 붙여넣기
내계정@gmail.com|비번|시크릿 → [붙여넣기 반영 + 2FA 검증] → 미리보기 코드 6자리 나오는지
3
프록시 1줄 검증
홈 ④ 또는 프록시 탭 → [검증] → Proxies: 1 이상
4
검색어·도메인
실제 검색될 단어 + 내 사이트 도메인. 테스트는 클릭수 2, SERP 2페이지 권장 (검색 탭)
5
[시작 전 점검]
빨간 ✗ 없으면 준비 완료
6
미리보기 (DRY RUN)
브라우저 없이 배정만 로그에 찍히는지 확인
7
▶ 원클릭 시작 (LIVE)
실시간 상태: 로그인 → 2FA 코드 표시 → 인증 완료 → 검색·클릭 순으로 변하는지 관찰
8
여러 계정
2~3줄 붙여넣기 후 시작 → 계정 1/3, 2/3 … 진행, 실패해도 다음 계정 계속되는지

[2FA] 코드 클립보드 복사 완료: 482193
[Google] 2FA 코드 자동 입력 중… (482193)
