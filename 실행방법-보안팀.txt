========================================
  Octo 소탕 시스템 — 정확한 실행 방법
  (보안팀 · 구글 광고 타겟 추적 · 1클릭)
========================================

[ 구성 ]
  웹사이트     = 작전 리모컨 (START/STOP · 설정 · 실시간 위젯)
  OctoAgent.exe = PC 연결 프로그램 (반드시 상주)
  Octo Browser  = 실제 프로필 창 (검색·클릭)

[ 사이트 ]
  URL  : http://66.29.149.197:8787/
  ID   : admin
  PW   : Desktop\Octo-Web-Login.txt 참고

[ 1단계 · PC 준비 ]
  1. Octo Browser 실행 → 로그인 유지
  2. Local API 활성 (기본 127.0.0.1:58888)
  3. 바탕화면 OctoAgent.exe 더블클릭
  4. 창에 「연결됨 · 대기 중」 / 「Octo: Local OK」 확인
  5. 이 창을 절대 닫지 말 것 (게임 오토처럼 상주)

[ 2단계 · 웹 입력 ]
  1. 브라우저로 사이트 로그인
  2. 좌측 「PC 에이전트」 초록/파랑 = 연결 성공
  3. Google 계정 추가 (email|비번|2FA시크릿)
  4. 검색어 여러 개 (「변형 확장」으로 다양화 가능)
  5. 타겟 사이트(도메인) 입력 — 추적 대상
  6. 프록시 입력
  7. 작전 모드 확인
       ☑ 1클릭 모드
       ☑ 검색어 로테이트 / 셔플
       ☑ 폴백
       ☐ 광고 스킵  (꺼 두면 광고도 추적)
       ☑ 광고 우선 추적
  8. Octo API 토큰 입력 → 저장

[ 3단계 · START ]
  1. ▶ START 작전
  2. Octo 창이 여러 개 뜨면 정상 (동시 프로필)
  3. 흐름: 구글로그인 → 다양검색 → 타겟 1클릭 → 체류
  4. 통제판 「실시간 작전 추적」 카드로 확인
  5. 끝/중단 시 ■ STOP

[ 한 프로필 루프 = 오토 게임 1판 ]
  Octo 프로필 Start
    → (선택) Google 로그인 + 2FA 자동
    → 검색어 A/B/C… 중 해당 프로필 순서로 조회
    → 타겟 도메인 또는 광고 매칭 시 정확히 1클릭
    → 체류·스크롤 로그
    → 프로필 Stop → 다음 계정

[ 자주 하는 실수 ]
  · 에이전트 안 켬 / 창 닫음 → 작업 전달 안 됨
  · 옛 exe 사용 → 반드시 Desktop\OctoAgent.exe (최신)
  · 검색어·도메인 비움 → 실패
  · Octo 로그아웃 → Local API 실패

[ 파일 위치 ]
  Desktop\OctoAgent.exe     … 통합 에이전트
  Desktop\Octo-Web-Login.txt … 웹 로그인
  이 폴더\agent\OctoAgent.exe … 백업 복사본
