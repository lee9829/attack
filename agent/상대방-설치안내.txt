========================================
  사이트 연동 에이전트 — 상대방(작업 PC) 안내
========================================

이 프로그램은 "사이트"와 "내 PC의 Octo Browser"를 연결합니다.

  [사이트 관리자]  웹에서 설정·시작 버튼
        ↓
  [이 에이전트]    상대방 PC에서 실행 (지금 설치하는 것)
        ↓
  [Octo Browser]   프로필·프록시로 구글 클릭 실행


■ 필요한 것
  1) Windows PC
  2) Python 3.10 이상  https://www.python.org/downloads/
     (설치 시 "Add Python to PATH" 체크)
  3) Octo Browser 설치 + 본인 계정 로그인
  4) 이 폴더 전체 (프로젝트 zip 또는 GitHub 다운로드)


■ 설치 (최초 1회)
  1. 압축을 풀거나 폴더를 받습니다
  2. agent\config.env 파일을 메모장으로 엽니다
  3. 사이트 관리자에게 받은 값으로 수정:

       AGENT_SERVER=http://(사이트주소):8787
       AGENT_USER=admin
       AGENT_PASS=(웹 로그인 비밀번호)

  4. agent\1-의존성설치.bat  더블클릭 → 끝날 때까지 대기


■ 매일 사용 순서
  1. Octo Browser 실행 → 로그인
  2. agent\2-에이전트실행.bat  더블클릭
  3. 창에 연결 메시지가 보이면 성공 (창 닫지 말 것)
  4. 사이트 관리자가 웹에서 [시작] 누르면
     이 PC Octo로 작업이 자동 실행됩니다


■ 역할 정리
  - 사이트(서버) : 설정 화면, 시작 버튼, 로그 보기  → 관리자
  - 에이전트(이 PC) : Octo 연결, 실제 브라우저 작업   → 상대방
  - 서로 인터넷으로 통신합니다 (같은 방에 있을 필요 없음)


■ 문제 해결
  - "오프라인"     → 2-에이전트실행.bat 다시 실행, config.env 확인
  - "401" / 로그인 → AGENT_USER / AGENT_PASS 가 웹 비밀번호와 같은지
  - Local 실패     → Octo Browser 가 켜져 있고 로그인 됐는지
  - Python 없음    → Python 설치 후 1-의존성설치.bat 다시


문의는 사이트 관리자에게 하세요.
