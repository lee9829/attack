아직 분석 안 함

파일로 넣기 (프로젝트 폴더)

  • urls.txt / sites.txt — 전체 URL·도메인 섞어 넣기
  • domains.txt — 도메인만
  • paths.txt — path·정규식
  • keywords.txt — 검색어
  • accounts.csv — email,password,otp_secret (구글+2FA)

권장 운영 (대규모)

  1. 계정 여러 개: email|비번|2FA시크릿 (홈 ②)
  2. 프록시 = 계정 수 이상 (Octo 출구 IP)
  3. 검색어 + 위 대량 URL
  4. 동시 프로필 3~10 · SWARM 시작
  5. 각 Octo 창: 로그인→2FA 자동→검색→목록 매칭 링크만 클릭

쿠키 주입 (자사 사이트 테스트)

Octo 브라우저 컨텍스트에 쿠키를 넣습니다. 본인 사이트 QA용입니다. Google/타사 계정 탈취 목적이 아닙니다.
